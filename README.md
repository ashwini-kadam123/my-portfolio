# 👩‍💻 Personal Portfolio Website

Welcome to my personal portfolio repository! 
This website is designed to showcase my technical skills, academic achievements, web development projects, and professional background as a Computer Engineering graduate.

---

## 🚀 Key Features

* **Fully Responsive Design:** Optimized for all devices, including desktops, tablets, and smartphones.
* **Modern UI/UX:** Clean layout with smooth interactive enhancements, specialized custom logo brandings, and hover transitions.
* **Dynamic Skill Visualization:** Utilizes native animated progress bars to accurately display technical proficiency across diverse core domains.

* **Direct Professional Inquiries:** Pre-configured mail integrations for immediate recruiting communications.
